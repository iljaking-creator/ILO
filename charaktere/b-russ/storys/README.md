# Storys — „Fit mit Schicht", Staffel 1 (Phase „Erkennen", Form F1)

Ein Drehbuch pro Folge, jeweils mit 6-Panel-Storyboard (Job-IDs im
`../../manifest.json` unter `storyboards`).

## Format-Regeln für jede Folge

- **Format:** 9:16 Hochkant, 24 fps, Ziel-Länge 35–45 s
- **Hook:** Sekunde 0–2 muss das stärkste Bild der Folge zeigen — nie mit
  Logo oder Begrüßung starten
- **Form:** Staffel 1 durchgehend Körperform **F1** („10 Jahre Schicht")
- **Orange-Regel:** Warnweste ist das einzige orange Element pro Frame
- **Natrium-Gelb #E8B84B:** nur als Nachtlicht im Hintergrund, nie auf Russ
- **Abbinder:** jede Folge endet auf die Catchphrase **„Schicht für
  Schicht."** + Serien-Titelkarte (identisch in jeder Folge — der
  Wiedererkennungs-Stempel)
- **VO:** Russ spricht selbst (trockener Kollegen-Ton, kein Guru), kurze
  Sätze, Pausen aushalten
- **Text-Overlays:** maximal 5 Wörter pro Karte, Stanzpapier #C9C6BE auf
  Nacht #16181C
